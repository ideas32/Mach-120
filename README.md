# Mach-120
Voron 0 sized all-metal super DIY 3d printer

Capable of a [sub-2m benchy (1:56)](https://youtube.com/shorts/lzrwitsjRUY?feature=share)

## Overview
- 120x120x120mm build volume
- CoreXY motion system built on NEMA 23 steppers and 2gt-6mm belts
- Leadscrew-driven Z-axis (manual bed leveling)
- Highly rigid custom sheet-metal frame
- Lightweight moved masses designed with deflection under acceleration in mind
